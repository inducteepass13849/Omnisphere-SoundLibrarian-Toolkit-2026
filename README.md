## Frequently Asked Questions

**Q: Is this tool compatible with the latest version of Omnisphere 2.8 and beyond?**
A: Yes, the 2026 Toolkit is designed for full compatibility with Omnisphere version 2.8 and all anticipated future updates from Spectrasonics. It reads the standard library file structures.

**Q: Does this application modify or bypass any software licensing?**
A: Absolutely not. This is a standalone management and librarian utility. It does not interact with, alter, or circumvent any copy protection, activation systems, or license keys for Omnisphere itself. It is designed solely for organizing your legally obtained sound libraries.

**Q: What are the system requirements?**
A: The toolkit requires Windows 10 (version 1909 or later) or Windows 11, 4 GB of RAM, and 500 MB of free disk space. An active internet connection is needed for initial download and future updates.

**Q: I'm having trouble locating my Omnisphere installation. What should I do?**
A: Common paths include `C:\Program Files\Spectrasonics\Omnisphere` or within your DAW's plugin folder (e.g., `C:\Program Files\Steinberg\VSTPlugins\Spectrasonics`). You can use the 'Scan' feature in the toolkit's setup wizard to help find it automatically.
